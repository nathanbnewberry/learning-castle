# The Learning Castle

A math game for kids: a knight answers questions to block enemy attacks, beats five bosses, and builds a castle. One HTML page, no server, runs in any modern browser (built for iPad Chrome).

Play: https://nathanbnewberry.github.io/learning-castle/

Progress is saved in the browser on the device you play on. Parents: the Parents panel on the start screen sets each child's lesson mode and the level locks.

Prototype. Designed by Finnley, built with Claude.

## Cannon Math Pirates

Second game, same idea with pirate ships: https://nathanbnewberry.github.io/learning-castle/pirates/

Answer math to fire the cannon, sink ships, build your island, fight off the British, and dive to the cursed skeleton city. Progress is saved in each device's browser.
